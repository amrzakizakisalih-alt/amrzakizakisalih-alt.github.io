## 🌟 Caractéristiques & Design

- **Architecture Bento Grid (Inspirée de Linear / Aceternity UI)** : Mode sombre profond, bordures fines, effets de flou (glassmorphism) et cartes interactives.
- **Orientation Recruteur / CV** :
  - Métriques clés immédiatement lisibles (promo, partenariats Cerema, technologies).
  - Bouton de copie rapide de l'adresse email professionnelle avec notification toast.
  - Liens directs vers les dépôts GitHub de chaque projet.
- **Richesse Visuelle** :
  - Vrais graphiques de résultats scientifiques intégrés (ACP normée sur données biomédicales, séries temporelles InSAR / GRACE du Cerema).
  - Lightbox modale interactive au clic sur les graphiques pour agrandir et analyser les figures.
  - Schéma orbital vectoriel (dynamique $N$-corps).
- **5 Rapports de Recherche INSA (PDF)** :
  - Téléchargeables ou consultables en 1 clic directement depuis les cartes projets.
- **Filtrage Dynamique** : Filtres instantanés par thématique (*Calcul & HPC*, *Génie Logiciel*).
